# Expense Tracker – Mobile Finance Management App

The **Expense Tracker** is a cross-platform mobile application built using **Flutter** and powered by **Firebase (Auth, Firestore, Storage)** to help users monitor income, expenses, budgets, and spending patterns. Designed through detailed prototypes in **Figma** and implemented with clean Flutter UI components, the app delivers a simple, intuitive, and analytics-driven finance experience with real-time cloud syncing.

## 🚀 Overview

The app provides users with a complete financial overview by allowing them to record transactions, set budgets, analyze spending patterns, and track progress through visual charts. Built using an incremental development approach, it ensures smooth UI flow, reliable state handling, and secure backend communication using Firebase.

---

## ✨ Key Features

### 📥 Add Income & Expenses  
- Log daily income and expenses  
- Add descriptions, amounts, and categories  
- Smooth forms with validation for quick entries  

### 🏷️ Category-Based Tracking  
- Categorize transactions (e.g., Food, Transport, Shopping, Bills)  
- Filter and view spending by category  
- Visual cues to show where money is going  

### 🎯 Budget Management  
- Set monthly or category-specific budgets  
- View remaining budget in real time  
- Visual feedback when nearing or exceeding budgets  

### 📊 Real-Time Analytics & Insights  
- Dynamic charts showing monthly spending trends  
- Category-wise breakdowns and comparison graphs  
- Helps users understand patterns and make informed decisions  

### 🔄 Real-Time Cloud Sync  
- All data stored in Firestore  
- Auto-sync across devices  
- Offline-first behavior where supported  

### 🔐 Secure Authentication  
- Firebase Authentication for login & signup  
- Password reset functionality  
- Secure user sessions with validation  

### 🎨 Clean, Modern UI (Designed in Figma)  
- Minimalistic layout with a focus on readability  
- Responsive UI optimized for Android devices  
- Custom reusable widgets (buttons, fields, cards)  
- Smooth transitions and scroll-safe screens  

### 📂 Profile & Settings  
- Upload profile image (Firebase Storage)  
- Edit profile details  
- View total monthly income, expenses, and balance at a glance  

### ⚙️ Stability & Performance  
- Tested across multiple Android versions  
- Optimized asset loading and state management  
- Clean error handling and validation mechanisms

## 📝 Summary

The **Expense Tracker** app provides a complete financial management experience with simple transaction logging, powerful analytics, real-time syncing, and intuitive UI design. It enables users to visualize their spending behavior, plan budgets effectively, and maintain control over their financial health — all through a modern, responsive, and secure mobile interface.
