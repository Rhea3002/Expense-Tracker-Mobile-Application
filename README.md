# Expense-Tracker-Mobile-Application
Built a cross-platform finance tracker app for managing income, expenses, and budgets with real-time reporting. Integrated Firebase for secure storage, auth, and cloud sync. Designed a clean, user-friendly UI in Figma and ensured stability across Android builds. Featured in BITMAP 4.0.
